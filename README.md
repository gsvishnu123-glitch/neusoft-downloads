# NeuSoft downloads

This public repository is reserved for verified NeuSoft release metadata and approved downloadable release artifacts. It contains no application source.

No customer installer is published yet. Before adding a release, require owner acceptance, production signing, device/installer acceptance, immutable versioned assets, SHA-256 verification, and source-commit provenance. Do not upload internal, debug-signed, unsigned, or otherwise unaccepted builds.

`releases.json` is intentionally empty until an approved customer release is published. The live NeuSoft website is not configured to read this repository in this preparation phase.
